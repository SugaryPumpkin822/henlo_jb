# henlo
webkit-based jailbreak for Playstation Vita/TV on firmware 3.65+

![bootstrap-idle](https://user-images.githubusercontent.com/30833773/211209121-d036c67b-9ed3-444c-b4d2-5932ad5466e5.jpg)

## usage
visit ```jailbreak.psp2.dev``` using the Playstation Vita/TV web browser

![pic-browser-idle](https://user-images.githubusercontent.com/30833773/211209156-1e204953-e533-43e8-aba6-69f8840626a8.jpg)

## this project is currently in the beta phase
focus1: bootstrap stability and overall functionality
focus2: add capabilites for lower firmware all the way down to the lowest version existing on a psVita
focus3: add a payload to install apps that u pick from a checkbox
focus4: add a payload to lower firmware
focus5: make the payloads better and test them over and over
focus6: add a payload to copy the operating system over a webserver that u pick to download and export to your pc as a iso
